# ygokdogan.dev

Yusuf Emir Gökdoğan'ın kişisel portfolyosu: Unity araçları ve sistemleri, itch.io oyunları ve GitHub projeleri.

Sade HTML, CSS ve JavaScript; derleme adımı yok.

- İçerik: `data.js` (profil, oyunlar, private projeler, görevler, başarımlar)
- GitHub repoları ve profil sayfa açılırken GitHub API'sinden çekilir; `repos.json` ve `profile.json` yedektir.
- Simgeler: [Lucide](https://lucide.dev) (ISC) ve [Simple Icons](https://simpleicons.org) (CC0), `index.html` içinde gömülü.

Yerelde çalıştırmak için:

```bash
python3 -m http.server 5173
```
